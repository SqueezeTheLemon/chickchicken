chickchicken

⬇️ Chickchicken 데스크톱 앱

방송 목록을 보고 녹화방송·라이브를 재생하는 데스크톱 클라이언트예요.

🪟 Windows

Windows 10 / 11

파일아키텍처형식
Chickchicken-win-x64-setup.exe x64 (Intel·AMD 64비트)설치 파일
Chickchicken-win-x64.zip x64설치 없이 실행
Chickchicken-win-arm64-setup.exe ARM64 (Snapdragon 등)설치 파일
Chickchicken-win-arm64.zip ARM64설치 없이 실행

설치·실행

  1. 설치 파일(…-setup.exe)을 내려받아 실행해요.
  2. 코드 서명이 없는 앱이라 "Windows의 PC 보호"(SmartScreen) 창이 뜰 수 있어요 → 추가 정보 → 실행을 눌러요.
  3. 설치 위치를 고르고 설치하면 바탕화면·시작 메뉴에 Chickchicken이 생겨요.
  4. zip을 받았다면 압축을 풀고 Chickchicken.exe를 실행해요(설치 없음).
  5. 삭제: 설정 → 앱 → Chickchicken → 제거

🍎 macOS

macOS 11 Big Sur 이상

파일아키텍처형식
Chickchicken-mac-arm64.dmg Apple Silicon (M1~M4, arm64)디스크 이미지
Chickchicken-mac-x64.dmg Intel (x64)디스크 이미지
Chickchicken-mac-arm64.zip Apple Silicon앱 압축 파일
Chickchicken-mac-x64.zip Intel앱 압축 파일

설치·실행

  1. → 이 Mac에 관하여에서 칩이 Apple M…이면 arm64, Intel이면 x64 파일을 받아요.
  2. .dmg를 열고 Chickchicken을 응용 프로그램 폴더로 끌어다 놓아요.
  3. Apple 공증(서명)을 받지 않은 앱이라 처음 실행 때 막혀요. 아래 중 하나로 열어요.
    • 응용 프로그램 폴더에서 Chickchicken을 Control+클릭(우클릭) → 열기 → 열기
    • "손상되었기 때문에 열 수 없습니다"가 뜨면 터미널에서 xattr -dr com.apple.quarantine /Applications/Chickchicken.app 실행 후 다시 열기
    • 또는 시스템 설정 → 개인정보 보호 및 보안 아래쪽의 그래도 열기
  4. 삭제: 응용 프로그램 폴더에서 Chickchicken을 휴지통으로

처음 실행하면

  1. 앱이 기본 서버(배포한 백엔드)에서 방송 목록을 불러와요.
  2. 방송 카드를 누르면 재생돼요. 녹화방송은 바로, 라이브는 HLS로 5~10초 늦게 재생돼요.
  3. 다른 서버에 연결하려면 오른쪽 위 ⚙️ 서버 설정에 주소를 넣고 연결 테스트 → 저장을 눌러요.
  4. 댓글·후원은 🌐 웹에서 열기로 웹 사이트에서 할 수 있어요.
